| 2 Layout | Recover correct reading order on two-column pages — the single biggest lever on transcription quality found in A1 (CER 0.77 -> 0.04 after reconstruction). | Page images + `data/toc.json`'s `category` field (proxy for column count — see caveat). | None — heuristic gutter-split, not a trained layout-detection model. | 1 region (full page) for Biography/Poem categories, 2 regions (left/right of the horizontal midpoint) for Comedy/History/Tragedy. **Assumption, not a per-page detection** — `toc.json` has no per-page `layout_type` field; flagged in code for whoever owns Layout/OCR to confirm against the real scans. | `Region.bbox` + `kind='text'` only; page size read via PIL, falls back to a fixed 300-DPI page size if a file can't be opened. | No automated tests yet. | Runs once per corpus, CPU-only, ~ms/page. | None yet — would need monitoring if a real per-page `layout_type` ever becomes available and disagrees with the category-level assumption. |
| 3 OCR | Read column-reconstructed text off each page. | Pre-computed `data/ocr_text/{page,bio}/*.txt` (already produced externally, via `codes/q3_4B_gt_part1..4.ipynb`). | `Qwen/Qwen3-VL-4B-Instruct`, prompted zero-shot per page image (not fine-tuned) — traditional OCR engines (Tesseract/PaddleOCR/EasyOCR/docTR) were benchmarked and rejected for catastrophic accuracy on this corpus's archaic typography; see `notebooks/eda.ipynb` Stage 4. | This stage **loads pre-computed transcriptions** rather than re-running OCR live per region — a documented trade-off (see `vision/ocr.py`'s docstring): OCR already ran once, offline, with reading-order reconstruction already applied. | `Region.page_id` -> pre-computed text file; multiple Regions per page (two columns) collapse to one `Chunk` per page since the source file already has correct reading order. | Real, saved CER/WER benchmark exists in `notebooks/eda.ipynb` Stage 4 (comparing Tesseract/PaddleOCR/docTR/EasyOCR, the engines that were rejected); no saved CER/WER run yet for the shipped Qwen3-VL-4B-Instruct output itself against `grading_kit/labels.jsonl` — see `codes/A2_form.md` Section 5. | OCR itself already ran once, offline (Kaggle, 4 notebooks, one per ~330-page chunk of the corpus); this stage is a cheap file read at pipeline-run time. | None yet — no OCR-engine-version tag stored alongside `data/ocr_text/`. |
